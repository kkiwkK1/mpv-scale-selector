# 缩放选择器插件 — P1 骨架用户说明

> 阶段说明：这是 P1 骨架（状态管理与菜单框架），**尚未接入任何真实缩放算法**。
> 它只在隔离测试配置中验证过；未写入你的活动 mpv 配置。
> （p1-002 限域修正后：档位表解析器对未实现档位有硬保护，详见下文"配置硬保护"。）

## 快捷键

| 键 | 作用 |
|---|---|
| `F8` | 打开 / 关闭缩放选择器菜单 |
| `↑` / `↓` | 在菜单中移动（自动跳过禁用项） |
| `Enter` | 确认当前项 |
| `Esc` | 关闭菜单 |

F8 可在 `script-opts/scale-selector.conf` 改（`key_menu=...`）。菜单打开时
↑/↓/Enter/Esc 被菜单临时接管，关闭后立即恢复 mpv 默认行为。

## 菜单里有什么（P1）

- **关**（唯一可选）：恢复插件接管前的你的原始配置。**不等于停止 mpv 必需的缩放和色彩管理**。
- **LS1**〔禁用〕：无公开源码/权重/移植许可，无法原样内置；不以替代算法冒名。
- **BCAS**〔禁用〕：算法定义身份未核实；不以 CAS/Bicubic+CAS 冒名。
- FSR1 / NIS / SGSR1 / Anime4K / xBR / Sharp Bilinear / Integer / Nearest〔禁用〕：
  未实现/后续阶段（P2/P3）。

## 状态含义（菜单顶部实时显示）

| 状态 | 含义 |
|---|---|
| `off` | 未接管。你的配置原样。 |
| `active（档位）` | 已接管并应用了某档位。 |
| `external` | 检测到外部修改（如你按了 CTRL+1..6 换 Anime4K 链、其他脚本改了属性）。**插件立即让出，绝不覆盖你的改动**。菜单里会提示先选〔关〕处理差异。 |
| `fallback（原因）` | 档位应用失败（文件缺失/非法配置/值被 mpv 拒绝）。显示真实原因并回退到上一稳定状态，无半生效残留。 |

## "关"的精确语义

按下"关"时，插件逐项比较**当前值**与**自己最后写入的值**：

- 还是自己写的值 → 恢复为接管前的基线；
- 已被你/其他脚本改过 → **保留你的改动**（OSD 与日志会说明保留了哪些项）。
- shader 链按元素处理：只移除插件自己加的条目，你追加的条目原样保留；
  绝不使用"清空整个 shader 链"的粗暴操作。

## P1 的边界（请勿期待）

- 选了档位也**没有**真实缩放算法在跑——本阶段只有"关"是真实档位，其余全是禁用占位。
- 状态在 mpv 重启后回到 `off`（P1 不持久化；插件不写任何状态文件）。
- 菜单观感、字号、文案是否可接受，属于人工确认项（P1-UC-1..4），自动测试只证明功能与状态真实。

## 配置硬保护（解析器强制，不依赖默认配置文件）

- **关不可动**：无论 `gears=` 怎么写，"关"始终存在、始终在菜单第一项、始终可用；
  写 `off_mode=disabled` 或删掉 off 都只会得到告警并回到强制行为。
- **未实现档位无法被启用**：LS1、BCAS、FSR1、NIS、SGSR1、Anime4K、xBR、Sharp Bilinear、
  Integer、Nearest 在真实实现落地前，无论怎么改档位表（省略 `_mode`、写 `active`、
  配 `_set`、改 `_label/_reason`）都强制保持禁用，且始终使用内建固定名称与原因，
  不会被替换成其它算法冒名；尝试覆盖会在日志产生告警。
- **自定义档位**（如测试桩）必须显式写 `_mode=active` 才可选（缺省为禁用）；
  自定义档位的显示名不得使用保留算法名（LS1/BCAS/关等），否则该档位被禁用并在
  菜单标注配置错误。
- **收敛规则**：重复档位 id 只产生一个菜单条目；重复配置键保留第一个值并告警
  （与日志文字一致）。

## 文件

- `scripts/scale-selector.lua` — 插件本体
- `script-opts/scale-selector.conf` — 键位/字号
- `script-opts/scale-selector-gears.conf` — 档位表（含禁用原因文案；修改原因文案只需改 `*_reason=`）
