# 缩放选择器插件 — P2 真实档位用户说明

> 阶段说明：P2 在 P1 骨架上接入了 **4 个真实档位**（FSR1 / SGSR1 / Anime4K / Nearest）。
> 插件只在隔离测试配置中完成客观自测；**未写入你的活动 mpv 配置，未部署**（P2 当时口径；
> 2026-10-12 已手动安装到日常 mpv，现状以 README 为准）。
> 菜单观感与画质偏好等你确认的事项仍为 pending（见文末）。

## 快捷键（与 P1 相同）

| 键 | 作用 |
|---|---|
| `F8` | 打开 / 关闭缩放选择器菜单 |
| `↑` / `↓` | 在菜单中移动（自动跳过禁用项） |
| `Enter` | 确认当前项 |
| `Esc` | 关闭菜单 |

## 菜单档位（P2 现状）

| 菜单项 | 状态 | 说明 |
|---|---|---|
| **关** | 可选 | 恢复接管前你的原始配置（见下文"关的语义"）。 |
| **FSR1** | 可选 | AMD FidelityFX Super Resolution v1.0.2（EASU+RCAS，LUMA 双 pass，MIT）。仅放大时运行（每轴 ≤2×；超出部分由 mpv 原有 scaler 接管，菜单会如实备注）。 |
| **SGSR1** | 可选 | Qualcomm Snapdragon Game Super Resolution v1（单 LUMA pass，BSD-3-Clause，luma 适配版）。仅放大时运行。 |
| **Anime4K** | 可选 | 本机原有 stock 链的零改动副本（Mode A..F 对应原 CTRL+1..6 六条链，默认 A）。字节与你的配置逐哈希一致。 |
| **Nearest** | 可选 | 最近邻：`scale/cscale/dscale` 三核全部 nearest（点采样，含缩小），无 shader 链。RGB 源也可用。 |
| LS1 / BCAS | 禁用 | 文案不变：LS1 无公开源码/许可；BCAS 身份未核实。不以替代算法冒名。 |
| NIS / xBR / Sharp Bilinear / Integer | 禁用 | P3 占位。 |

## 换档语义（P2 重要变化：整链替换）

- 一次只有**一条插件主链**。选中某档位 = `glsl-shaders` 整个 property 替换为该档位
  自己的链（不是往你现有链上追加）。FSR1 配方就是 `[p2-FSR1.glsl]` 一项；
  Nearest 配方是**空 shader 列表** + 三核 nearest。
- **首次接管也整链替换**：如果"关"状态下你已用 CTRL+1..6 挂着原 Anime4K 链，此时选
  FSR1，插件会先快照你的完整链再整链替换；选**关**时完整恢复你原来的整条链。
- **外部修改优先**：active 状态下你按 CTRL+1..6（或其他脚本改了 glsl-shaders），插件
  立即让出（状态 external）。之后选**关**会**保留你的完整外部列表**（同名条目也不删），
  绝不凭路径字符串删你重新加的条目。
- **external 状态下拒绝换档**：插件不静默接管、不追加，菜单会提示先选〔关〕处理差异。

## 守卫（RGB / HDR）

- RGB 像素格式或 HDR 传递函数（PQ/HLG）时，LUMA 类档位（FSR1/SGSR1）在菜单
  中如实标注不可用原因（明示 RGB/HDR），选择被拒绝且**无任何残留写入**；
  播放中切换到 RGB/HDR 会自动释放并如实回退。
- Nearest 不设 LUMA 守卫（RGB 也可用）。
- 2026-10-12 修正（SHD-2）：Anime4K 的全部 hook 在 MAIN/PREKERNEL（无 LUMA hook），
  改归 MAIN 档——RGB 输入可用，HDR 输入仍禁用（独立 HDR 守卫）。
- 注：P2 的 HDR 守卫验证基于元数据覆盖合成（非 HDR 编码片源），不做任何 HDR 画质评价。

## 失败回退（无半生效）

- 档位资源缺失：立即 fallback，原因明示缺哪个文件（如 `shader 文件缺失: ~~/shaders/p2-SGSR1.glsl`）。
- shader 编译失败/未生效：激活后插件核对 vo-passes 中本链真实 pass（带帧新鲜度核验，
  不凭旧帧报"已生效"），失败则整体释放回"关"，缩放核恢复你接管前的真实值，
  OSD/日志显示"链验证失败（缺失: …）"。全程无半生效残留。

## 状态显示与诚实性

- 菜单顶部状态含义与 P1 相同（off/active/external/fallback）。
- 视频显示区域 ≤1×（非放大）时选择 FSR1/SGSR1：链按算法自己的 `//!WHEN` 合法跳过，菜单如实
  显示"跳过"，**不会假装算法在跑**；窗口尺寸变化/换片/裁剪/暂停恢复都会重新评估，
  不会留陈旧 pass。「显示区域」不含黑边（2026-10-12 修正 SHD-1：此前按整窗口判断，
  如 1920×800 片源全屏于 1080p 屏时会误判为放大，约 5 秒后报「验证失败」并回退）。
- 窗口超每轴 2× 时 FSR1 如实备注"超出部分由 mpv scaler 接管"。
- 状态以 mpv 重启后回到 `off`（不持久化，不写状态文件）。

## 配置

- `script-opts/scale-selector.conf`：`key_menu`（默认 F8）、`anime4k_chain`（a..f，默认 a）。
- 档位的链与身份内建固定：conf 里写 `fsr1_label=…` 等覆盖会被忽略并产生日志告警
  （防冒名/防换链）；"关"恒为"关"，不可被 conf 改名/禁用。
