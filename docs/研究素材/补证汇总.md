# 剩余五项与现成 mpv port 的补证

本轮补证通过两个独立研究角色分别核对 FSR/NIS 与 LS1/SGSR/BCAS，整合者再次读取官方说明和实际 shader。结论已纳入 [主报告](../可行性研究报告.md)，最终审查不等于所有早期初稿已获接受。

## FSR1

- 官方：GPUOpen-Effects/FidelityFX-FSR，MIT；空间 EASU + RCAS，不是 FSR2/3。
- 已下载 `证据/port-FSR.glsl`，两个 LUMA hook，每轴最多2×。
- mpv来源：https://gist.github.com/agyild/82219c545228d70c5604f865ce0b0ce5
- 路线：复用port，先做SDR YUV与输出尺寸/跳过条件验证；RGB需适配或回退。未在本轮编译播放。

## NIS

- 官方可读仓库：NVIDIAGameWorks/NVIDIAImageScaling，README含MIT全文、颜色域与NVScaler已有锐化的说明。
- 已下载 `证据/port-NVScaler.glsl`，一个LUMA compute hook，两张系数纹理，6-tap/64-phase。
- mpv来源：https://gist.github.com/agyild/7e8951915b2bf24526a9343d951db214
- 首轮研究中的官方README/许可证404是路径核对不足，不代表官方项目没有公开许可；整合者已补齐。
- 路线：复用NVScaler，先验证compute、写入边界与RIFE竞争；不默认叠加NVSharpen。未做运行实测。

## SGSR1

- 官方：Qualcomm Snapdragon GSR；SGSR1空间单pass，SGSR2时域，BSD-3-Clause。
- 已下载 `证据/port-SGSR.glsl`；LUMA、单fragment pass、新式PARAM。
- mpv来源：https://gist.github.com/agyild/7715b6b1f38427839d58f80884902cab
- port明确由绿色通道改为亮度通道，并有修正/优化，不等于LS中RGB版本的数值复刻。
- 路线：复用现成port，比从SDK零移植更直接；兼容与HDR钳制尚待测试。

## LS1

- Steam官方公告确认“小而快的通用神经网络”、约1×–2×设计范围。
- 本轮未取得源码、权重和移植/再分发许可。LSFG被商店称为专有不能直接拿来证明LS1的授权状况。
- 原样内置没有实施依据；使用另一个开源网络或自训网络只能独立命名。

## BCAS

- 未从本轮取得的官方商店说明和公告中核实全称/算法定义，不猜Bicubic/Bilinear/Bilateral。
- CAS本体有开源实现及mpv port：https://gist.github.com/agyild/bbb4e58298b2f86aa24da3032a0d2ee6
- CAS/CAS-scaled、Bicubic+CAS候选工程可做，但不能因此声称复现BCAS。
- 若需截图同款，需补充来源软件的版本或权威算法说明。

## 获取与运行边界

成功和失败路径均在 `../证据/网络取证索引.json`、`../证据/移植取证索引.json` 留存；raw port URL含具体内容修订，文件有SHA-256记录。取得源码不等于编译、播放、效果或速度已经通过本机验收。
