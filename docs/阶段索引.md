# 阶段索引：docs 下各阶段文档的角色与现行有效性

- **性质**：只读索引（评审整改 M-15）。本文**不移动、不重命名任何文件**：`docs/执行授权-P*.json`、`docs/P2实施计划.json`、`docs/P3实施计划.json`、`docs/P3启动基线.json`、`docs/P4启动基线.json`、`docs/P4实施计划.json` 等被 `taskflows/` 门禁脚本按**路径**引用并校验哈希（实测：`taskflows/p2_guard.py:44`、`p3_guard.py:13-15`、`p3_revision_guard.py:60-61`、`p4_guard.py:10-14`），且 `docs/P4启动基线.json` 的 `preserved_file_hashes`（实测 106-109 行）登记了四份执行授权的 SHA-256——移动即门禁 FAIL。
- **有效性判据**：v1/v2 并存时按**文件修改时间**与**后续文档引用**判权威；阶段收口后，计划/基线转为「证据链保留」（仍有效，供追溯，不再是活动输入）；快照类是中断点留证，不设权威。「mtime」均取自本会话 `stat` 实测。
- 本索引只描述 2026-10-11 时点状态；后续 session 新增文档应自行追加登记。
