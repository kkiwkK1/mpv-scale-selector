## 2. 测试环境与隔离规范（所有产品测试强制）

- **活动配置零未授权使用**：一切测试用 `--config-dir=<临时目录>`；写 APPDATA/mpv 仅在 P5 且用户明确同意、并完成部署前新快照之后。
- 进程隔离：未来产品测试的HOME/APPDATA、watch-later、shader缓存等定位到专用临时路径，不改变真实环境变量或读取凭据；不在原媒体上写入。测试输入用专门准备的片段（彩色条、像素图案等合成源），逐个记录 SHA-256。本轮标准库单测的目标仅在系统临时目录，Windows临时目录可能物理位于用户目录内，但不会改动日常配置/凭据。
- 固定后端：显式 `--vo=gpu-next` 与选定 GPU API（首版）；记录 mpv 版本（本机 `v0.40.0-393-gad59ff1b4`、libplacebo `v7.357.0`）与显卡环境。
- 每次记录（模板，写入 `docs/验证/`，按 `P<阶段>-<组ID>` 命名；未来产物不预建死链接）：档位/算法角色、shader 来源 URL 与版本 SHA-256、输入文件 hash、候选 commit/hash、vo/gpu-api、参数（锐化等）、RIFE 开关、已知限制。失败同样记录。
- 证据文件只增不改；更正以追加条目方式注明。

## 3. 性能测量规范（PER 组前提，其他组不得引用性能结论）

- 本计划采用的 GPU 数据源：`vo-passes` 原生 node（desc、last/avg/peak/samples；耗时值单位**纳秒**，÷1e6 得毫秒；samples为耗时样本，非纳秒单位的样本数量）；必须区分 fresh 与 redraw 帧。它不是所有可用GPU分析工具的唯一来源；若补用其他工具，单独记录口径。
- 采集流程：先预热（触发 shader 编译/缓存）→ 固定采样窗口/样本数 → 记录 GPU 温度/时钟波动；连续读取滚动samples时要防重复统计，不把avg/peak重采样伪装为逐帧原始分布。掉帧与帧节奏另测（dropped帧计数、帧时长分布）；测试开始前固定采样/聚合方法。
- 预算口径：48fps≈20.83ms/帧、60fps≈16.67ms/帧只是输出节奏预算，不是 RIFE 与 shader 可相加的独立预算；共存余量以实测为准。
- 禁止：用启动墙钟/总帧数、pass 数量比冒充 GPU 耗时；数据不足时记"未测"，不得下结论、排名或宣称"更快"。
