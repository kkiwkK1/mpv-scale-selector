## 2. 运行时状态机

```
off --(选择档位：快照基线)--> active --(外部修改托管属性)--> external
 ^                              |                             |
 |                              +---(档位应用失败)--> fallback(原因，回退上一稳定档位)
 +-------- 关：仅恢复拥有且未被外部改动的属性 <------(关)------+
```

- **接管**：首次选择真实档位时快照全部托管属性（core：`glsl-shaders`/`scale`/`cscale`/`dscale`
  ＋档位表声明可能写入的显示几何属性，如 `video-zoom`）。快照后复读一遍，检测接管竞态。
- **active**：一次仅一档。换档先归还上一档写过、本档不再设置的属性（恢复基线，仅限仍归
  插件所有者），再写入新档位值；`glsl-shaders` 按元素级替换：新链 =（当前链 − 插件添加项）+ 新项，
  **外部条目按序保留**，绝不使用 `glsl-shaders-clr`。
- **external**：`observe_property` 上任一托管属性值 ≠ `last_written`（未写过的属性 ≠ 基线）即判定
  外部修改：让出、OSD 提示、菜单显示 external。自身写入靠"值 == last_written"天然屏蔽
  （先更新账本再触发观察回调），无标志位竞态。external 状态下选择普通档位被拒绝
  （提示先选〔关〕处理差异），**永不静默覆盖**。
- **关**：逐属性比较当前值与 `last_written`：
  - 相等（仍拥有且未被外部改动）→ 恢复基线；
  - 不等（外部改动）→ **保留外部状态**。`glsl-shaders` 特殊：按元素级仅移除插件添加项、
    保留外部条目及顺序（既不全清、也无插件残留，也不陈旧覆盖）；
  - 输出 `off_report`（restored/kept_external/notes）到 OSD、日志与 `user-data`。
  - 无额外交互确认弹窗（按 P1 计划口径：diff 即当前属性 vs last-written 的所有权判定）。
- **fallback**：档位应用失败（shader 文件缺失预检 / mpv 拒绝写入 / 读回不一致）时回滚本次
  已写入属性到应用前值、恢复 `owned_shaders`，显示真实原因，回到上一稳定档位
  （首次接管失败则释放所有权回到 off）。无半生效残留（CTL-07 客观验证）。
- **退出清理**：P1 不持久化、不写任何状态文件；shutdown 仅记录终态并移除菜单。
  CTL-05 证明四种状态 quit 后配置目录逐文件 SHA-256 不变、重启回到 off。
- **首次接管失败**（快照竞态/计划失败/资源缺失）→ 释放所有权回到 off 并显示原因。

## 3. 关键实现决策

1. **档位表来自 `script-opts/scale-selector-gears.conf`（自解析）**而非 mp.options：
   mp.options 无法预先声明动态档位键（测试桩需要注入 `p1-test-*` 档位），自解析对未知键/
   损坏行给出告警并跳过（CTL-06）。`<id>` 限 `[a-z0-9-]`，conf 键名中 `-` 写作 `_`。
2. **`_set` 语法**：`属性=值`（set）、`glsl-shaders+=路径` / `glsl-shaders-=路径`（元素级链操作）。
   禁止对 `glsl-shaders` 直接赋值，防止档位配置写穿外部链。P1 产品档位无任何 `_set`。
3. **读回校验 + 类型归一**：mpv 会把数值属性规范化（`video-zoom="0.25"`→`0.25`），
   `last_written` 记录**写后复读的实际值**；比较用容忍数值/字符串差异的 `values_equal_tol`。
   mpv 静默拒绝非法值（如 `scale=p1-test-invalid`，Lua 调用不报错但属性未变）由读回校验兜底
   （CTL-07 实测触发"读回不一致: scale"并正确回滚）。
4. **F8 菜单**：`add_key_binding` 仅绑定 `key_menu`（源内恰 1 处）；菜单打开期间
   `add_forced_key_binding` UP/DOWN/Enter/Esc，关闭即移除。光标**跳过禁用项**（禁用项不可能
   被选中，ENTER 双重保险仍拒绝）。菜单内容同步导出到 `user-data/.../menu_entries`
   （含 id/label/enabled/reason/selected），是"菜单显示与事实一致"的机读依据。
5. **GEO-01 防反馈**：显示几何唯一来源是 `video-out-params`（`read_display_geometry`，P3 使用）；
   插件所有属性读取走 `jget()` 并记入 `read_journal`（导出至 user-data）。GEO-01 运行时断言：
   journal 只出现 `glsl-shaders/scale/cscale/dscale/video-zoom/video-out-params`，无
   解码参数/shader 输出尺寸读取路径。
6. **user-data 导出**（IPC 客观验证接口）：`state/stable_gear/gear/reason/menu_open/menu_entries/
   baseline/last_written/wrote/owned_shaders/off_report/read_journal/selftest`。
7. **selftest**：`script-message scale-selector-selftest` 在真实 mpv 内运行 43 项纯函数断言
   （解析/菜单模型/跳过禁用/换档计划/关的恢复矩阵/几何来源/保留档位身份/off 不变式/
   重复收敛/冒名拒绝/注册表零漂移），结果导出供 CTL-01/06 取证。

## 4. 静态审查事实（单测守护，见 `tests/test_p1_support.py`）

- 插件源码（剔除注释行后）无 `glsl-shaders-clr`、无 `change-list`——"关"与档位切换在代码层
  就不可能全清外部链。
- 键绑定：仅 `add_key_binding(o.key_menu)` 一处 + 菜单打开期间的 forced UP/DOWN/ENTER/ESC。
- `io.open` 仅以只读模式出现；插件不写任何文件（不持久化）。
- 随附档位表：`gears=off,...`（关在首位）、ls1/bcas `mode=disabled`、LS1 原因含
  "无公开源码/权重/移植许可"、BCAS 原因含"身份未核实"+"不以CAS/Bicubic+CAS冒名"、
  占位档位无 `_set`、无 `p1-test-*` 桩混入产品配置。

## 7. 已知限制

1. `screenshot-to-file` 不含 osd-overlay 菜单内容（本构建，对照实验证实）；菜单渲染事实以
   `menu_entries` 机读导出为准，观感属 P1-UC-1。
2. mpv.com 包装器改写含反斜杠参数（探针证据），程序化测试直呼 mpv.exe；不影响用户手动使用 mpv.com。
3. IPC 发现在高负载下偶发 Errno 22，客户端单次重连+重试并在 transcript 记录；重试可能使
   个别 keypress 重复（导航按"选中项==目标"收敛，语义安全）。
4. fallback 检测覆盖资源缺失/非法值/计划失败；shader 编译失败的运行时检测属 P2（需要
   vo-passes/hook 事实，P1 计划明确不含真实档位）。

## 8. p1-002 限域修正增量（brief：docs/P1/限域修正brief-v2.json）

### A. 配置解析器保留条目的身份与 fail-closed（原发现 technical:R1 major、safety:F-03 minor，均修复且保留原级）
- 内建保留档位注册表（PRODUCT_GEARS）：LS1/BCAS 及全部 P1 未实现产品 id 由**解析器层**强制
  `disabled` + 固定标签/原因；本地 conf 省略 `_mode`、显式 `active`、配 `_set`、改 `_label/_reason`
  一律无效并告警（显式 active/_set 另标 broken）——`_mode` 缺省不再等同 active。
- off 不变式：恒存在（缺失自动补）、恒首项（后置自动前移）、恒可用（`off_mode` 不能禁用），
  全部由解析器强制并告警。
- 重复 id 合并为单条目（修复旧实现判重时机错误）；重复键保留首个（与告警文字一致）；
  自定义档位 label 不得使用保留算法名（冲突即 broken+disabled+label 回退）。
- 真实变体：CTL-06 新增 e/f/g/h 四变体（保留 id active+_set 冒名 / 自定义档位 BCAS 冒名 /
  重复 id+off 后置 / 缺 off）；SHD-12 新增 conf-attack 变体；PIC-05 新增 no-mode 变体；
  Lua selftest 新增 15 用例（含内建默认表与注册表零漂移断言）。

### B. 截图失败的证据真实性（原发现 integration:F-01、technical:R2、safety:F-01，均修复且保留原级）
- 仅"命令成功且文件存在非空"的截图进入 files；失败变体在 `variants[].screenshot`
