## 1. 隔离与安全配方（所有 GPU 触碰强制）

1. 子进程环境白名单：`SystemRoot`/`windir`/`PATH(System32)`/`TEMP`/`TMP`；`HOME`/`USERPROFILE`/`APPDATA`/`LOCALAPPDATA` → `%TEMP%/p4-001/sandbox/…`；`PYTHONDONTWRITEBYTECODE=1`、`PYTHONNOUSERSITE=1`；移除全部 API 凭据 env；cwd=沙箱。
2. 活动 `%APPDATA%/mpv`、`D:/MPV`、私人备份 payload 零写；不装/卸载、不改 DPI/刷新率/电源/风扇/驱动、不全局 kill、不 git 提交推送。只终止**自有**子进程 PID（启动记录、退出核对）。
3. GPU 单 owner 串行；测量期他人负载按 §4 污染门处理（记录/暂停/拒绝，不杀）。
4. 媒体全部合成自生成，放 `%TEMP%/p4-001/media/`；git 内只入哈希与 ≤1280×720 预览。活动 `mpv.conf`/`rife.vpy` 正文不入 Git。
5. 单次代理调用超时 ≥ run 墙钟 + 60s；超时截短的 run 记无效并保留原始目录，禁止"数据不足还 PASS"。

## 3. 公平 A/B 分组（fairness）

主场景：SDR YUV 1080p→2560×1440 全屏。一次只挂一条主链。公平主比较的每个 arm（含全部插件档 arm）都从同一 `--profile=high-quality` 与完全相同的非算法控制项起步，唯一允许差异=所选主缩放链及其算法必需 owned 属性（scale/cscale/geometry，逐项列明）；**禁止 baselineHQ 用 HQ、其它 arm 用 defaults 后靠免责声明**。插件档位经真实插件 IPC 选择（产品路径）；`baselineHQ` 不加载插件脚本。B3 冻结逐 arm 渲染相关属性实读 diff/chain 表（scale/cscale/dscale/scaler-radius/deband/dither/sigmoid/colorspace/geometry 等，来自运行时属性实读）；非算法必需属性在 arms 间不同 → 该 arm 配置无效（E5），修复后才进 production；PIC-01 报告强制携带该表。

| 组 | 源→目标 | arms | 说明 |
|---|---|---|---|
| G1 equalrect 主组 | 1920×1080 → 全屏 rect 2560×1440 | baselineHQ(ewa_lanczossharp)、nearest、FSR1、SGSR1、NIS、SharpBilinear-AUTO、SharpBilinear-2x、Anime4K-ModeA | 同 rect 同组比较；AUTO 在此场景 floor(1440/1080+0.01)=1 → 退化为双线性，如实作"退化披露行"，不冒充有效对比 |

锐化参数静态绑定（PIC-03，本轮无扫档）：产品当前固定锐化参数、不开放运行时调档，故**不制造 default/+step/max 假三套扫档**（本轮明确 NOT_RUN_FIXED_PRODUCT_PARAMS）。B3 从 P3 交付 shader 原文件（只读）实读各 arm 默认参数值/可调范围/方向语义与机制差异（FSR1 RCAS 低值=更锐、方向反向；NIS 默认 0.25∈[0,1]；SGSR1 机制不同），冻结进 production manifest 并作公平性披露；不改 P3 shader/registry、不冒充产品默认身份；机器工件=默认参数下 gpu-next 真实输出+S 帧身份。不同算法锐度数字不等价：只报默认值/范围/机制差异，不凭先验宣称任何档有益或无益。

## 4. 采样协议（PER-01/03/04、CAL-01）

### 4.1 run 定义与窗口

- **独立重复单位 = 一次完整 run**：全新 mpv 进程，播完整个采样段，退出。滚动 buffer 内每个值不是独立样本。
- 媒体段 30s；预热 10..15s，稳定判据满足的首次轮询记 warmup_end；采样窗口 = [warmup_end, warmup_end+10s)；退出 = warmup_end+12.5s（EOF 守卫：媒体 30s 保证不提前 EOF，仍发生→run 无效 E6 保留）；`--no-loop` 禁循环，全程记录真实 PTS；窗口边界以 `time-pos` 单调增量核对，异常 run 剔除并保留。
- 轮询周期 1.0s：**同刻原子采样**（复用 `tools/p3_lib.py` `same_moment_sample` 语义，P2 VL-F1 教训）：一次快照内取 `video-out-params` + `osd-dimensions` + `vo-passes` fresh/redraw 全表（逐 pass `desc/last/avg/peak/samples` 原始 ns）+ 计数器族 + `time-pos`，落 JSONL，不做窗口内二次加工。
- **预热稳定判据（客观可执行）**：连续 ≥3 次轮询满足 (1) pass 集合 desc 列表一致；(2) 每 pass 计时非空（last/avg/peak/samples>0）；(3) `video-out-params` 渲染状态稳定（格式/尺寸/fps 无 reinit）；(4) 源活性=time-pos 单调前进、帧计数无回退；(5) GPU 温漂 ≤2°C。**显式废除『fresh 总 count 连增』要求**：vo-passes count/samples ≈10s 后饱和是滚动窗口已知行为，饱和不作失稳/停摆证据（LF-01）。GPU 帧新鲜度只由 CAL-01 在同一渲染流上受控步进校准（校准扰动与性能稳态 loop 严格分离：性能 run 禁截图/seek/加轮询，仅 1Hz 原子采样）；真实计时 run 以可得 fresh/renderstate+媒体 progress 佐证并诚实标注局限，不以解码活性/PNG 元数据冒充 GPU 新鲜。不满足→延长预热至 15s 上限，仍不满足 → run 无效（E4）。
- 固定参数：`--vo=gpu-next --gpu-api=vulkan --hwdec=no --fullscreen --osc=no --osd-level=0`（完整 CLI/config 模板在 B3 冻结并实哈希，为 production 唯一参数来源）。

### 4.2 滚动窗口诚实规则（RV2 不复犯）

- vo-passes last/avg/peak 为滚动窗口值，窗口边界未知重叠：**每 run 的诚实统计量 = 窗口内 10 次轮询的 per-pass `avg_ns` 快照分布**；run 汇总 = 该分布中位数；语义明确标注为"末段滚动平均的快照"，**非逐帧独立样本**。
- **禁止按值去重**：相同数值是真实不同帧的重采；不得把重采当独立样本；samples 是耗时样本计数，不得当独立帧数。
- 计数器（vo-passes count/samples 与 dropped 族）只做 run 内首末 delta；计数饱和/停增不单独断言播放器停摆（P3 GEO-03 教训），须以解码活性+pass 表现联合判断并记录饱和标志；32ns 倍数步长不单独断言硬件 timer 分辨率。
- ns÷1e6=ms；fresh/redraw 分列；**shader pass 总和 ≠ 端到端 GPU 时延**，两者分列；pass 数/FPS/启动墙钟/IPC 开销永不作 GPU 时间。
- 跨 run：有效 run 中位数 + 对 n 个 run 的 bootstrap（n=10000，seed 424242）描述性百分位区间；重复不足不做显著性检验、不做绝对优劣外推。IPC 轮询空载开销（CAL-01 实测）仅记录不扣除。

### 4.3 重复次数与顺序（预注册）

- n（全部整数）：主分层每 cell **5 个有效 run**；G2b/G3 每 cell **3**；pilot 2（产品参数固定，无扫档 run）。drop-affected run 一律保留计入，不因效果方向剔除；仅先验污染（E1-E3）/采集无效（E4-E6）剔除并保留原因码。
- 全部 seed 定值：顺序 seed=20261007、bootstrap seed=424242、MEDIA_SEED=20261007，每 clip 派生 seed=int(SHA-256('p4-001/'+clip_id) 前 8 字节十六进制,16) mod 2^32（禁 Python 进程随机 `hash()`，F-07）。
- 顺序设计术语精确化（LF-07）：n=5 用 5 个固定 per-block permutation（Fisher-Yates by 顺序 seed）+相邻 block 反转，n=3 用 3 个；这是固定 per-block 置换+反转设计，**不是严格 ABBA 完全平衡**，奇数 n 的残余顺序不平衡如实披露；RIFE off/on 校准对按反转交替。顺序表随 production manifest 冻结，B5 按表执行，B6 复算一致。

### 4.4 污染与剔除门（全部预注册）

| 门 | 阈值 | 动作 |
|---|---|---|
| 观察语义 | WDDM 下逐进程图形显存常 N/A（F-04）：门值只取全 GPU 字段（memory.used/utilization.gpu/temperature.gpu/clocks.sm）；`--query-compute-apps` 可得时仅辅助记录；绝不把全 GPU 值称作『其他进程』值；观察源缺失→该门记 unverifiable 并披露，不得空真 | — |
| 启动前 | 全 GPU memory.used 相对勘察基线 1004MiB 增量 >1500MiB，或全 GPU util ≥10% 持续 ≥5s（排除自有 PID 后），或存在非自有 mpv.exe 进程 | 不启动（E1），记录等待重查 |
| run 中 | GPU ≥83°C 或 run 内升温 ≥8°C 或核心时钟 <起始观测 90% | run 无效 |

## 5. 帧节奏与呈现来源（PER-02、TIME-01）

1. B3 在固定构建实测候选属性：`dropped-frame-count`、`decoder-frame-drop-count`、mistimed/delayed/vo-delayed 计数、`estimated-vsync`/vsync-jitter 族——逐项记录可用/不可用/单位/reset 或累计语义；只做 run 内 delta + 饱和标志。
2. **真实 present 帧时长：未测**（PresentMon 缺失；ETW 提权不获授权不使用）。可报告 = renderer 指标（fresh/redraw 节奏、dropped/mistimed delta）+ 媒体节奏 proxy（源 fps 与 RIFE 2× 后 container fps 核对）。**IPC 轮询间隔与 time-pos 差值不得当呈现帧时长**。帧时长分布未测不得称帧节奏完成；违者 EVI-01 判 FAIL。
3. 升级路径：用户明确授权 PresentMon 安装/提权采集 → 另行预注册修订 + 新目录复测，不静默扩权。
4. 预算口径：48fps≈20.83ms / 60fps≈16.67ms 仅作输出节奏预算参考列，**禁止当作 RIFE 与 shader 可相加的独立预算**；RIFE 共存只做同 pipeline OFF/ON 配对实测（PER-03）：OFF run=全 S 帧统计、ON run=S/M 混合帧统计，vo-passes 在 ON run 内无 S/M 帧类粒度、不做单独 GPU 归因；无端到端/present 时间 → 不给数值总余量 ms、不反推 RIFE 时延；禁止 CPU walltime/日志/帧序凑 GPU 余量。性能测量的墙钟采样窗口只是观测安排，绝不表述为屏幕 present 间隔或帧时长。
5. PER-04：NIS compute 档 × RIFE on 的竞争观察（pass 表现/fresh-redraw 区分），扩展自 P3 后端验证；无数据记未测。

| pixelart | 480×360 24fps 30s（720 帧） | 8×8 块调色板图案，每帧滚动 2px，seed 派生不变；延长后仍执行每段128MB及媒体总量700MB门，超限阻断不删原件 | G3 |

- 生成：`tools/p4_lib.py` 确定性 Python 生成 PNG 帧；MEDIA_SEED=20261007，每 clip seed=int(SHA-256('p4-001/'+clip_id) 前 8 字节十六进制,16) mod 2^32（禁 Python 进程随机 `hash()`）；生成器版本/参数=必需依赖（p4_lib.py 冻结 sha256+参数表写入 manifest）→ 经固定构建 mpv `--o` 一次性转码 FFV1(yuv420p) 封装（固定参数+输出实哈希绑定；保证 LUMA 链真实 YUV 输入）。
- **编码器回退梯（预注册）**：ffv1(yuv420p) → ffv1 变体 → PNG 序列直读（此时 LUMA 档在 RGB 输入的真实跳过行为按产品语义如实降范围并声明，不冒充 YUV 全覆盖）。
- 体量：媒体总量 ≤700MB、单段 ≤128MB（30s 段含 LF-02 的 warmup/窗口/加载余量，不降时长——降时长破坏测量窗一致性，超限时按预注册先查磁盘再降采样数）；**媒体与全分辨率 PNG 原件（合成、无私密内容）持久保留于证据树逐 hash 绑定，TEMP 仅作生成暂存（LF-06）**。

## 7. 捕捉与帧身份（PIC 组）

1. 捕捉 trial：gpu-next/Vulkan 真实窗口受控帧步进 + 截图（`--osc=no --osd-level=0`），记录实际 rect/`osd-dimensions`；`--vo=image` 仅限 RIFE 滤镜输出鉴别专用 trial，**明确非 gpu-next shader 渲染证据，绝不供 PIC-01/02/04 算法 A/B**；捕捉 trial 与性能稳态 run 严格分离（校准扰动不进计时 run）。
2. PNG 先检后用：尺寸/位深/实际视频 rect/OSD-free（四角纯黑 + 标记条定位）/帧身份（帧号标记条 ↔ 源帧唯一映射，同帧才能跨 arm 拼图）。
3. CPU golden：nearest/integer 类做精确像素块比对；lanczos 类用 Python 重采样近似做帧身份与结构校验（不冒充逐像素等价）；M 帧判据见 §2 四件套 c。
4. 盲评材料：通过检查的 PNG 建立盲标签 + seed 随机顺序（写入 manifest），评分程序预注册于 `docs/P4/P4用户盲评说明.md`；无模型替用户评分；**合成不得冒充自然动画/实拍完成 PIC-01**。
5. 全分辨率 PNG 原件（合成、无私密内容）持久保留于证据树并逐 SHA-256 绑定（不以 TEMP-only/缩略预览替代可复核原件，LF-06）；git 只入哈希+≤1280×720 预览；证据树 PNG 原件预算 ≤600MB，启动前实测目标盘 free≥2×总预算（D: 勘察时 free≈144GB），不足→先报告再按预注册降采样数，不牺牲原件。

## 8. 证据与门（EVI-01、PER-05）

- 每 trial 独立 create-only 目录；已存在即拒绝启动 mpv（工具内实现+单测）；全部句柄关闭+self PID 退出后才写 manifest；失败目录保留，补测走新目录。
- manifest：全部产物实算 SHA-256 + plan/tool/config-template/media/seed/顺序/环境 JSON 哈希 + log/console/transcript + vo-passes JSONL + 计数 delta 表 + PNG。
- 反指标扫描（`tools/p4_check_evidence.py`，机器门）：无 vo-passes JSONL 支撑的耗时表述；无 run 数/CI 的"更快/更慢"；仅 FPS 的 RIFE PASS；"帧节奏完成"而 present 未测；被剔除 run 消失；证据目录重用。任一命中 → EVI-01 FAIL。
- 中断恢复：先对实际工件/源码 SHA/自有 PID 核对再续，禁止盲重放非幂等写者；每 JSON 决策走合同+机器门，不靠叙述就绪。
- 状态词汇：per-test = PASS_OBJECTIVE / PARTIAL_MEASURED / PENDING_USER / BLOCKED_ENV / FAIL / 未测；per-stage = PASS_OBJECTIVE_WITH_PENDING_USER / PARTIAL_MEASURED / BLOCKED_ENV / REWORK。任一 pending/blocked 必然体现于阶段状态；"没有提升/某档更慢/某指标无法获取"是有效实测结论；未测必需项不得包装全 P4 PASS。PIC 评分与默认档选择不可机器代签。
