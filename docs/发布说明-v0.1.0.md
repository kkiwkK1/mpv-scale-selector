# 发布说明 — scale-selector v0.1.0（2026-10-12）

mpv 缩放算法选择器的首个公开发布版本。中文为主；面向 mpv 用户，安装三途径见下。

## 这是什么

一个 mpv 插件：**F8 打开菜单，一键切换缩放档位**。共 12 项 = 关 + 9 个真实内建档位（FSR1 / NIS / SGSR1 / Anime4K / xBR / Sharp Bilinear AUTO / Sharp Bilinear 2× / Integer / Nearest）+ LS1、BCAS 两个**禁用占位**（LS1 是 Lossless Scaling 的神经网络放大模型；BCAS 全称与算法定义未核实）。托管属性（插件接管期间代为设置、关档时恢复的 mpv 属性）快照恢复、外部改动让出、着色链逐一验证、失败自动回滚——菜单显示的状态与实际生效状态一致。功能与操作详见 [README](../README.md)。

## 安装三途径

目标目录均为 mpv 配置目录（Windows 默认 `%APPDATA%\mpv`；portable 版 mpv 的配置目录是其旁的 `portable_config`，安装时用 `-ConfigDir` 指定即可，见下）。

### 1. clone + 一键安装器（推荐）

```
git clone https://github.com/kkiwkK1/mpv-scale-selector.git
cd mpv-scale-selector
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -Yes
```

（双击 `tools\install.bat` 亦可。）

退出码：0 成功；1 参数/环境/IO；2 预检阻断（源损坏）；3 未安装（仅 `-Verify`）；4 不一致（仅 `-Verify`）。**升级 = 重跑同一条命令**（冲突自动备份 `.bak-scale-install-<时间戳>`）；卸载加 `-Uninstall`（只删与源哈希一致的 21 项清单文件，`input.conf`/`mpv.conf`/既有文件从不被动过）。

### 2. Release zip

从 GitHub Releases 下载 `v0.1.0` 的源码 zip，解压后进入解压目录，同样运行 `tools\install.bat`（安装器按 `tools\` 位置自定位仓库根，与 clone 等效）。

### 3. 手工三步

把三组文件复制到配置目录对应位置（保持相对结构）：`scripts\scale-selector.lua` → `scripts\`；`script-opts\` 两个 conf → `script-opts\`；`shaders\` 整目录（含 `anime4k\` 子目录）→ `shaders\`。缺文件时相应档位失效并显示回退原因。

装完即可：打开视频 → 按 **F8**。LUMA 档（FSR1/SGSR1/NIS）需 YUV 平面格式素材（yuv420p/422/444 均可，RGB 系与 HDR 输入会被拒用）；RGB 源上灰显是设计行为。

## 本版亮点

- **菜单体验**：滚轮导航、首尾循环、**✓当前**标记、小键盘 Enter、选档后菜单保持打开、插件消息显示在菜单状态头（菜单顶部的一行状态文字）内
- **直切档**：`script-message scale-selector-set <id|off>` / `scale-selector-cycle next|prev`，与菜单同一入口、同一可用性规则
- **链验证显示**：档位激活后先显示「验证中」，着色链核对通过后才显示「已验证」；未生效时自动回滚并显示原因
- **一键安装器**：21 项清单、逐文件 sha256、三态安装、`-Verify`/`-Uninstall`、退出码表
- **验证结果**：单元测试与 Lua 内置自测（124 例）全部通过；一键安装器安装后 21 项清单逐文件哈希核对一致；与 RIFE 2× 插帧常驻环境共存，档位激活与恢复正常（行为细节见 README「兼容性说明」）

## 已知限制

1. **LS1 / BCAS 为永久禁用占位**：LS1（Lossless Scaling 的神经网络放大模型）无公开源码/权重/移植许可；BCAS 全称与算法定义未核实（仅凭字母不能认定是 Bicubic/Bilinear/Bilateral CAS）。不是「待实现」——该状态为固定行为，不受本地配置影响。
2. **主观画质未评**：全部验证由自动化测试完成；画质/性能测量尚未完成。本仓库不对画质做任何推荐，工程可行 ≠ 画质必然提升。
3. **安装器仅验证于 Windows PowerShell 5.1**；PowerShell 7（pwsh）未验证。
4. **mpv 版本口径**：开发与验证环境为 mpv git 快照构建 `v0.40.0-393-gad59ff1b4`（v0.40.0 之后第 393 个提交的开发版，非官网正式版本号）+ libplacebo `v7.357.0`（gpu-next，Windows）。官网正式版本未验证，不声明更低版本的兼容下限。
5. **PUC Lua 5.1 构建的 mpv** 上 Integer 档 `video-zoom` 会算错（源于 `math.log(k,2)` 在 PUC Lua 5.1 的兼容性问题，仅影响 Integer 档的缩放比）；官方 Windows 构建（LuaJIT）不受影响。
6. 默认 **F8** 为插件菜单键；冲突只可能来自你自己的 `input.conf` 或其它脚本——安装器会检查 `input.conf` 并警告；可改键或留空改用 `script-binding scale_selector/scale-selector-menu`（见 README「键位与脚本接口」）。
7. 启动日志固定 6 条「覆盖被忽略」告警——插件忽略对内建/占位档位的本地配置覆盖键，属预期行为。

## 升级、卸载与回滚

- 升级：重跑安装器（三途径任一），哈希不符的清单文件自动备份后替换。
- 卸载：`powershell -ExecutionPolicy Bypass -File tools\install.ps1 -Uninstall`；运行中的 mpv 重启后插件即消失。
- 回滚：冲突备份以 `.bak-scale-install-<时间戳>` 命名留在原目录，多次升级会累积、可手动删除（`scripts\` 下的备份会被 mpv 目录扫描看到，在日志里留一条无害加载错误）；安装器还提供 `-Verify` 随时核对 21 项清单状态。卸载时哈希不符的清单文件会被**拒绝删除**并逐项列出（防误删你的改动），确认不要后按清单路径手动删除。
