# 发布说明 — scale-selector v0.1.0（2026-10-12）

mpv 缩放算法选择器的首个公开发布版本。中文为主；面向 mpv 用户，安装三途径见下。

## 这是什么

一个 mpv 插件：**F8 打开菜单，一键切换缩放档位**。共 12 项 = 关 + 9 个真实内建档位（FSR1 / NIS / SGSR1 / Anime4K / xBR / Sharp Bilinear AUTO / Sharp Bilinear 2× / Integer / Nearest）+ LS1、BCAS 两个**诚实禁用占位**（LS1 是 Lossless Scaling 的神经网络放大模型；BCAS 全称与算法定义未核实）。托管属性快照恢复、外部改动让出、着色链逐一验证、失败自动回滚——菜单如实反映真实生效状态。功能与操作详见 [README](../README.md)。

## 安装三途径

目标目录均为 mpv 配置目录（Windows 默认 `%APPDATA%\mpv`；mpv 旁存在 `portable_config` 时不适用）。

### 1. clone + 一键安装器（推荐）

```
git clone https://github.com/kkiwkK1/mpv-scale-selector.git
cd mpv-scale-selector
:: 双击 tools\install.bat，或：
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -Yes
```

退出码：0 成功；1 参数/环境/IO；2 预检阻断（源损坏）；3 未安装（仅 `-Verify`）；4 不一致（仅 `-Verify`）。**升级 = 重跑同一条命令**（冲突自动备份 `.bak-scale-install-<时间戳>`）；卸载加 `-Uninstall`（只删与源哈希一致的 21 项清单文件，`input.conf`/`mpv.conf`/既有文件从不被动过）。

### 2. Release zip

从 GitHub Releases 下载 `v0.1.0` 的源码 zip，解压后进入解压目录，同样运行 `tools\install.bat`（安装器按 `tools\` 位置自定位仓库根，与 clone 等效）。

### 3. 手工三步

把三组文件复制到配置目录对应位置（保持相对结构）：`scripts\scale-selector.lua` → `scripts\`；`script-opts\` 两个 conf → `script-opts\`；`shaders\` 整目录（含 `anime4k\` 子目录）→ `shaders\`。缺文件时相应档位失效并如实显示回退原因。

装完即可：打开视频 → 按 **F8**。LUMA 档（FSR1/SGSR1/NIS）需 YUV 平面格式素材（yuv420p/422/444 均可，实测 420 与经 RIFE 的 444；守卫只拒 RGB 系与 HDR）；RGB 源上灰显是设计行为。

## 本版亮点

- **菜单体验**（7d2c0ec）：滚轮导航、首尾循环、**✓当前**标记、小键盘 Enter、选档后菜单保持打开、消息并入菜单状态头（不再与菜单重叠）
- **直切档**：`script-message scale-selector-set <id|off>` / `scale-selector-cycle next|prev`，与菜单同一入口、同一守卫
- **诚实显示修复**：黑边场景 `//!WHEN` 镜像改按视频显示矩形计算放大比；Anime4K 重新归 MAIN 档、RGB 源可用；无视频时选 Integer 不再泄漏接管状态；激活后先「验证中」、验证通过才「已验证」（修复 chain_verified 恒真 bug）
- **一键安装器**：21 项清单、逐文件 sha256、三态安装、`-Verify`/`-Uninstall`、退出码表；两轮隔离自测（覆盖全新安装/幂等重跑/冲突备份/校验/卸载往返与异常路径）
- **实测验收**：RIFE 插帧共存矩阵 7/7（另过环境清理核查）；日常 mpv 实装 21/21 哈希核验 + GUI 实测通过（F8 菜单 / FSR1 激活与链验证 / 恢复基线 / 日志无 traceback）；Lua 内置自测 124/124；干净检出 `Ran 646 / OK (skipped=36)`

## 已知限制（如实）

1. **LS1 / BCAS 为永久禁用占位**：LS1（Lossless Scaling 的神经网络放大模型）无公开源码/权重/移植许可；BCAS 全称与算法定义未核实（仅凭字母不能认定是 Bicubic/Bilinear/Bilateral CAS）。不是「待实现」，解析器层硬保证其恒不可选。
2. **主观画质未评**：全部验证为机器客观口径；P4 画质/性能测量进行中、未收口。本仓库不对画质做任何推荐，工程可行 ≠ 画质必然提升，更不承诺与 Lossless Scaling 逐像素一致。
3. **安装器仅实测 Windows PowerShell 5.1**（两轮隔离自测）；PowerShell 7（pwsh）未测。
4. **mpv 版本口径**：开发与验证环境为 mpv `v0.40.0-393-gad59ff1b4` + libplacebo `v7.357.0`（gpu-next，Windows）。不声明更低版本的兼容下限（早期草稿的「mpv ≥0.38」声明经独立读者评审撤销：无实测依据）；README 徽章与正文同口径，只标实测版本。
5. **PUC Lua 5.1 构建的 mpv** 上 Integer 档 `video-zoom` 会算错（源于 `math.log(k,2)` 在 PUC Lua 5.1 的兼容性问题，低危）；官方 Windows 构建（LuaJIT）不受影响。
6. 默认 **F8** 为插件菜单键；mpv 出厂默认键位未启用 F8（官方模板 `etc/input.conf` 中 `#F8 show-text ${playlist}` 是注释掉的示例），冲突只可能来自你自己的 `input.conf` 或其它脚本——安装器会检查 `input.conf` 并警告；可改键或留空改用 `script-binding scale_selector/scale-selector-menu`。
7. 启动日志固定 6 条「覆盖被忽略」告警，为防冒名解析器的预期行为。
8. 开发分支当前本机 24 个单测按设计失败（fail-closed：源码整改后，开发期记录的资源完整性基线待内部流程「重封」；相关测试等该流程收尾，不影响插件功能）；干净检出全绿（36 个依赖本机证据树的 P4 用例自动跳过）。
9. 若此前手动装过旧版（如 2026-10-12 手动安装的构建），**重跑一键安装器即升级**到本版。

## 升级、卸载与回滚

- 升级：重跑安装器（三途径任一），哈希不符的清单文件自动备份后替换。
- 卸载：`powershell -ExecutionPolicy Bypass -File tools\install.ps1 -Uninstall`；运行中的 mpv 重启后插件即消失。
- 回滚：冲突备份以 `.bak-scale-install-<时间戳>` 命名留在原目录，多次升级会累积、可手动删除（`scripts\` 下的备份会被 mpv 目录扫描看到，在日志里留一条无害加载错误）；安装器还提供 `-Verify` 随时核对 21 项清单状态。卸载时哈希不符的清单文件会被**拒绝删除**并逐项列出（防误删你的改动），确认不要后按清单路径手动删除。
