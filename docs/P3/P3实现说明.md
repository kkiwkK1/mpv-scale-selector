# P3 实现说明（session p3-001）

本文件为 P3 阶段实现说明，属 `docs/P3实施计划.json` write_paths 授权范围。
它如实记录 P3 交付内容、语义与验证方式；不宣称部署、验收或画质/性能收益。
人主观验收（菜单观感、像素风偏好、系统 DPI/跨屏实操）始终 pending，另行立项。

## 1. 阶段范围与状态

P3 在 P2 四档（fsr1 / sgsr1 / anime4k / nearest）基础上新增五个内建档位，
全部走 P1/P2 既有单主链状态机（off / active / external / fallback），不新建并行机制：

| 档位 | 算法 | 资源 | 许可 |
| --- | --- | --- | --- |
| `nis` | NVIDIA Image Scaling v1.0.2（compute 32×24×256 + 两张 2×64 rgba32f 系数纹理；内含锐化，绝不叠 NVSharpen；全 barrier 后逐像素边界 guard；`//!WHEN` 仅放大生效原样保留） | `shaders/p3-NIS.glsl` | MIT（取证 `docs/证据/port-NVScaler.glsl`） |
| `xbr` | Hyllian xBR-lv2（libretro 参考 MIT 版；MAIN RGB hook；参考 3× 预缩放 + mpv 后续缩放模式明示；xBR≠xBRZ） | `shaders/p3-xBR-lv2.glsl` | MIT（取证 `docs/证据/xbr-lv2.glsl`） |
| `sharpbilinear` | Sharp Bilinear AUTO（`floor(输出高/输入高+0.01)`；=1 明示退化为双线性；<1 钳制为 1 防除零） | `shaders/p3-Sharp-Bilinear-AUTO.glsl` | Public domain（Themaister） |
| `sharpbilinear2x` | Sharp Bilinear 手动 2×（参考坐标采样语义，非两 pass 串联；与 AUTO 分别命名） | `shaders/p3-Sharp-Bilinear-2x.glsl` | Public domain（Themaister） |
| `integer` | 整数倍缩放几何托管：`k=floor(min(原窗口像素/有效显示尺寸))`、`video-unscaled` + `video-zoom=log2(k)` + 三核 nearest；k<1 诚实缩小回退不裁切 | 空 shader 链（纯几何） | — |

新资源清单独立于 P2 十二项清单：`shaders/p3-resource-manifest.json`
（逐资源 sha256、取证基底哈希、许可说明见 `licenses/NIS-LICENSE-NOTES.md`、
`licenses/XBR-LICENSE-NOTES.md`、`licenses/SHARP-BILINEAR-LICENSE-NOTES.md`）。
P2 资源与 stock 十文件字节未动。

### 4. P3 新增 case 语义摘要

* **SHD-05 NIS**：静态审计（compute 指令、两系数纹理与取证逐字节一致、
  guard 位于全部 barrier 之后、barrier 前 return 禁止、WHEN 保留、不叠
  NVSharpen）+ 1366×768 非块整除真实放大 pass（DESC+非空 GPU samples+
  真实新帧+单文件链）+ 等尺寸/缩小合法 `skipped-when`（真实文案关联
  当前帧/epoch，链回退完好，不改 WHEN 凑激活）。
* **SHD-06 xBR**：21 个参考采样点静态对照 + 精确 3× 窗口的真实像素
  oracle（独立重推导 CPU replica 与纯双线性基线的边缘判别 + 平坦块
  保真）+ yuv 源 MAIN 生效 + 缩小窗口仍真实 pass；不冒 xBRZ。
* **SHD-07 Sharp**：AUTO floor=1 退化双线性 / AUTO 真实 2× / 手动 2× /
  scale0 钳制四个变体，每变体以参考坐标映射的 CPU golden 对真实截图做
  像素对照；菜单命名/SHA 相异不作为效用证明。
* **SHD-09**：五个新档位各自 8bit 与 10bit SDR 真实解码
  （same_moment pixelformat 与声明位数一致；10bit 需含 "10"）。
* **SHD-10/11**：逐档 RGB / HDR 守卫矩阵（P2 档 + P3 档同场实测；
  HDR 为元数据覆盖合成并如实标注；HDR 拒绝文案独立于 LUMA）。
* **GEO-02..06**：黑边（1080p→1440p k=1 边 320/180，主扫描被冻结 OSD
  污染时按几何构造无 OSD 扫描带 fallback 并如实标记）、k=2 满屏、k<1
  不裁切、同进程 loadfile k 1→2 + epoch 前进、nearest 严格 2× 块均匀度
  + 基线对照、窗口 resize/暂停后 k/epoch 重算、外改 zoom/GLSL 让出且
  Off 不回滚外部值、Integer→shader 几何转移与 Off 零残留、rotate/crop/SAR
  每相 k 与观察 vop(dw,dh) 推导一致（run-001 遗留空真被非空真门纠正）。
* **WINDOW-01**：resize/pause/aspect/loadfile/restart 链健康 + 结构化
  same_moment/freshness 记录。
* **PER-04-COMPUTE**：compute 后端可行性 + 原始 fresh/redraw GPU ns 样本
  （≥2 个正值、逐值记录、附 samples_note）；绝不宣称性能收益；RIFE 竞争
  依赖无受保护路径写入的证明不可得 → 如实未测留 P4。
* **UNIT-P3-01**：三个 P3 纯函数单测模块真实子进程实跑。
* **EVI-01**：把 `p3_check_evidence` 在系统临时沙箱合成 mini 证据树上
  实测：阳性对照必须全绿，10 类规范负例逐一真实植入并被检出；沙箱在
  证据目录之外，证据目录内零越名文件。
