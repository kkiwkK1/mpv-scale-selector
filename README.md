以下为研究概要。

针对 `Snipaste_2026-10-02_20-23-55.jpg` 中的方法菜单：

- **八项有明确mpv路线**：FSR1、NIS、SGSR1、Anime4K、xBR、Sharp Bilinear、Integer、Nearest Neighbor。
- FSR1/NIS/SGSR1已有源码可读取的mpv port；Anime4K官方即支持mpv，本机已有stock链。
- **LS1**：没有取得原网络源码、权重和移植授权，不能承诺原样内置。
- **BCAS**：准确算法定义未核实；CAS或Bicubic+CAS只能作为独立命名的候选。
- “关”应恢复用户原配置，不代表停止mpv所有缩放。
